# 实测记录

图像测试使用 Codex 内置 ImageGen。人物和服装均为虚构，审核由人眼按约定条件逐图完成。以下结果适用于这组素材。

| 场景 | 条件 | 观察与判定 |
| --- | --- | --- |
| S01 落肩 | 肩点与低肩缝可见 | 通过，两侧接缝可见 |
| S02 短衣长 | 衣摆在腰线附近，双鞋完整 | 通过 |
| S03 双贴袋 | 两个袋口和边线无遮挡 | r1 特意设为遮挡负例，未通过。只重做该镜头，r2 通过 |
| 条纹与亮面 | 中心门襟维持连续、均匀条纹，高光保留纹理 | 条纹未通过，门襟有明显空带。亮面纹理仍可见，通过该项 |
| 侧向走动 | 长下摆和双鞋完整，核对脸部轮廓与发型 | 下摆与双鞋通过。发型和雀斑接近，缺少同角度原始基准，侧脸精确一致性待确认 |
| 中文长标题 | 19 个汉字输入当前 18 字上限 | 预检拒绝，未进入出图 |
| 换图与局部重排 | 替换轮播第 2 页照片和文案 | 仅重排第 2 页，第 1 和第 3 页的文件字节一致 |
| 缺图与损坏输出 | 缺背面参考、缺页或输出尺寸错误 | 缺背面只拦截受影响镜头，缺页及错误尺寸无法通过交付预检 |

短夹克项目的首次通过为 **2/3**，平均返工 **0.33 次/镜头**，最终接受 **3 张**。该数字包含一张人为安排的负例，用于验证拒稿和单镜头补做流程。条纹、反光和侧脸为独立难例，未计入这组数据。比较不同生成工具时，复制相同项目和参考，以同一验收条件记录首次通过率、平均返工次数与入选数。本次实测使用一种生成工具。

在 macOS Apple Silicon 与 Node.js 22 上，执行 `npm ci` 后可运行 `node --test tests/project.test.cjs` 重放软件验证。测试使用已保存的虚构样例图。脚本核对 SVG / PNG 尺寸、图片数、来源稿号与像素，并生成项目缩略图和页序清单。照片中人物、动作、商品细节及裁切的判断仍需视觉复核。
