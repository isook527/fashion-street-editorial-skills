# Skill 行为评测

用同一宿主和模型运行两组。A 组仅安装目标 Skill，B 组使用未安装任何项目 Skill 的空工作目录。两组获得同样的任务、输入素材与工具，评测者不把 rubric 提供给模型。禁用生成扣费，任务只需文本或本地排版。

1. 触发评测逐条发送 `triggers.jsonl` 里的请求，记录宿主实际选择。空值表示两套 Skill 都不应触发。每次用新对话。
2. 任务评测把各目录的 `prompt.md` 和 `inputs.md` 中列出的输入交给模型。每项任务在每组运行三次，每次重建隔离目录和新对话。参考素材从样例读取。第三项在停点后用同一句确认语继续。
3. 逐项按 `rubric.md` 给 0 或 1 分，保存每次的输出、可核对证据、宿主与模型版本。每组通过率为三次通过的评分项数除以该任务所有评分项数。未运行的组记「待测」。
4. 汇总填进 [评测结果](../docs/evals.md)。有 Skill 和无 Skill 必须使用同样的评审标准。
