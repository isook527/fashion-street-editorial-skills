# 街拍状态与 CCD 质感

把“自然”“松弛”换成能被拍到的事实。每张图只给一个主要动作，补上身体重心、手与物品的接触、头部方向、视线和表情。取景决定描述粒度。全身先交代站位和脚步，半身先交代肩颈和手，局部写清材质和接触关系。

| 画面任务 | 可用的动作设计 |
| --- | --- |
| 展示长裤与鞋 | 跨过路面接缝，后脚尚未离地，镜头保持全身 |
| 展示开襟和内搭 | 在台阶旁停下，侧身面对街口，手放在前襟之外 |
| 展示袖口与配饰 | 一手轻握包带，另一手下垂，半身镜头保留腕部 |
| 拍到短暂表情 | 听到侧面声音后转头，嘴角轻抬，保持站位 |

写提示词时先交代输出与取景，再说明主体和搭配，接着写动作与场景，最后补镜头光线及必须保留的部分。要做系列时固定人物、搭配和拍摄条件，每镜只换本次指定的动作或机位。换场景时根据新空间解释光源，同时核对人物与衣服。

## CCD 风格

从光线出发：明确相机近轴直闪、环境光强弱和前后景亮度差。用少量早期数码感的细颗粒、亮部反射和边缘反差。先验证白色衣服仍有褶皱层次，肤色与衣色没被统一滤镜染偏，再扩展到其他镜头。

示例：夜色刚落，模特在店外台阶上停步，头转向镜头外侧，灰色针织上衣的袖口完整可见。近轴直闪照亮面部与衣服，橱窗暖光只留在背景。阴影有层次，针织纹理清晰。
