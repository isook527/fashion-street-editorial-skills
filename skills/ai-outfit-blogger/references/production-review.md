# 文案、逐图复查和稿号

文案可用「用途或问题 + 已核实的卖点」写标题，再用一段话交代搭配、光线和细节，给出话题与逐页 alt text。把「短衣长」翻译成「搭高腰裤，腰线更清楚」等可从当前图观察的利益，避免推定体型适配、显瘦效果或商品性能。alt text 描述画面所见和关键细节。验收术语保留在项目单，交付文案另列。

按镜头检查手指、纽扣、贴袋、双鞋、穿插、背景透视、文字及 logo。将可数的规格写成目标数字，并记录实际观察值。裁掉鞋的半身图可标不适用并写理由。无法从照片确认的项目用待确认，安排补拍或取证。

| 失败现象 | 修复路线 |
| --- | --- |
| 袋口或腰线被遮挡 | 换动作、机位或取景，只补受影响镜头 |
| 人物特征漂移 | 回到原始人物参考重做 |
| 缝线、按钮或标记错误 | 只修局部，再逐项核对 |
| 姿势与服装廓形冲突 | 换底图并重新匹配动作 |
| 色差或光线不稳 | 先匹配白平衡和参考光线，再复测色块 |

保留每稿的实际提示词、版本、工具、可见模型标识和 seed。工具不返回 seed 时记 null。记录修复原因、改动与验收结果，以相同条件汇总成功率。模型或工具变化后仍要重新核对生成结果。

真实人物只记录经确认的肖像授权范围和凭证位置。发布 AI 生成合成内容时按平台功能主动声明，保留有标识的原始文件，发布后再记标识状态和凭证。项目单与公开包之间的授权凭证由使用者在本地管理。

发布后录入真实展示、点击、收藏和评论关键词，计算点击／收藏占展示的比率。封面 A/B 使用同平台、同观察窗口、同一实验条件，记录样本量；对比结果写回品牌档案的审阅结论。

## 好与差

| 环节 | 可交给下一步 | 需要重做或补证据 |
| --- | --- | --- |
| 创意简报 | 「店开门前」，上午、左上方漫射光、安静支路，动作是经过木门时侧向迈步 | 「有氛围，像杂志」，分镜仍重复同一站姿 |
| 贴袋镜头 | 正面中近景，两只袋口和边线都可见，手臂离开衣身 | 一只手横在袋口上，仍记录两只贴袋验收通过 |
| 封面 | 缩到 360 px 后仍能看出短夹克和长裤的搭配，商品未被裁切 | 大字压在门襟上，观众只能看到品牌名 |
| 文案 | 「短夹克搭高腰长裤，腰线更清楚」 | 单凭一张图写「所有体型都显瘦」 |
