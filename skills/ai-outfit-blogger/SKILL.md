# AI 街拍穿搭博主

先确定交付是提示词、静态图组还是短动态，再确认人物、搭配、氛围、张数和画幅。只要提示词时交付逐镜可用的文本。需要生成时核对宿主是否支持参考图、编辑、所需画幅与视频等能力。

1. **分配参考职责。** 人物参考控制脸、头发与身形。服装参考控制款式、层次和可见细节。场景参考控制空间、机位与光线。动作参考只提供身体状态、表情和取景。没有人物参考且允许虚构时，选一张主体清晰的成图作为本组人物参考。
2. **根据衣服排动作。** 先识别搭配的体量、垂感、活动限制和必须展示的部位，再确定动作、重心、手脚、视线和取景。安排不同动作家族，遵守禁用动作。全身、半身、细节都计入约定总数。
3. **小样确定后扩展。** 先做代表镜头。组图逐张使用原始参考，只改变该镜头计划的变量。需要换装时优先选择廓形与目标衣服接近、手和衣服互相遮挡较少的底图。无服装图片时，按文字做示范搭配。
4. **对照复查。** 并排看人物、服装和成片，检查身份、版型、材质、关键细节、手脚、光影与取景。按原因回到选图、参考或局部编辑修正。只统计已取得且符合要求的图片，报告缺图和仍有差异的部位。

按需查阅 [lookbook 分镜与换装示例](references/shot-brief.md)、[街拍状态和 CCD 光线](references/street-states.md) 或 [静帧转短动态](references/motion-brief.md)。视频未生成时，交付物标明为动态分镜或提示词。

项目含具体商品时先区分商品保真与创意街拍。为每个卖点记录参考视角、镜头号、可观察的验收项和补拍条件。参考不足时标出缺口并推进可做镜头。使用双 Skill 仓库时按 仓库的项目工作流说明 交接项目单，或在独立使用时交付同样字段的表格。样张、参考和重做结果使用独立稿号；复查后只替换确需更新的镜头。
